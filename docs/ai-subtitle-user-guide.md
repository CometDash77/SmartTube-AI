## 1. 这个版本包含什么

| 能力 | 说明 |
| --- | --- |
| AI 字幕翻译 | 把当前选中字幕轨的原文按批送往你配置的服务，译文叠加显示；三种显示模式（仅原文 / 仅译文 / 双语） |
| 原文优先、失败降级 | 任何失败（无 Key、无网络、鉴权失败、限流、协议错误）都不影响原生字幕；原文照常播放 |
| 上下文本地化 | 时间轴、字幕正文与缓存全部留在设备上；只有固定协议里的“文本 + 稳定 id”离开设备 |
| 本地一键导出 | 遥控器两次点击导出**字幕 ZIP**与**诊断日志**，写入公共目录 `Documents/SmartTube/Exports/`，与 AI 开关、Key 完全解耦 |
| Key 安全保存 | API 23+ 用 Android Keystore + AES-GCM 加密后写入 no-backup 文件；API 17–22 只保留到本次会话 |
| 设置菜单 | 服务地址、模型、目标语言、翻译风格（可恢复默认）、Key 设置/清除、手动测试连接、状态行 |

## 2. 安装与升级

- **安装**：把 APK 传到电视（U 盘 / 文件管理器 / `adb install`）后直接安装。首次安装不需要卸载任何东西。
- **升级**：只有**同一签名**的 APK 才能覆盖安装。
  - 本候选若为 **debug 签名回退**（仓库没有签名 Secrets 时），那么它与上一次 nightly 候选**不是**同一个签名，
    Android 会拒绝覆盖；跨签名迁移必须卸载旧包，**会丢失该应用数据**（偏好、已配置的 Key），请先确认。
  - 项目签名（stable 身份）一旦建立，后续同一签名的候选与正式版都可以直接覆盖升级。
- **版本号策略**：仓库 `smarttubetv/build.gradle` 里的 `versionCode` 是**下一个稳定版预留号**（本次为 `2444`）；
  所有开发/验收候选统一使用 `versionCode - 1`（`2443`）。因此候选既能覆盖任何已发布版本，
  **稳定版又一定能覆盖候选**，并且 nightly 不会消耗未来的稳定版号。
- **回退**：Android 不允许降级安装（versionCode 更低会被拒绝），也没有无损回滚。
  需要回退时只能卸载后安装旧包，或使用备份；本版本不提供自动回滚。

## 3. 首次配置

进入路径：**播放视频 → 长按遥控器字幕键 → 字幕菜单 → 底部 AI 区**。

1. 打开 **AI 翻译（本视频）** 开关（仅对当前视频生效；新视频默认关闭，其它设置会被记住）。
2. 选择 **目标语言**（简繁中文在最前，其后英文、日文等；列表由程序固定，不依赖该视频有多少条翻译轨）。
3. 选择 **显示模式**：仅原文 / 仅译文 / 双语。
4. **AI 翻译设置**：在这里输入服务 Key（**遮蔽输入**，不会回填、不会打印、不会写入诊断或备份）。
5. **服务地址**（默认 `https://api.deepseek.com`）、**模型**（默认 `deepseek-flash`）、
   **翻译风格**（可选表达偏好，可一键恢复默认）。
6. **测试连接**：用固定合成文本发一次最小请求，结果分类提示（正常 / 未配置 / 鉴权失败 / 余额不足 /
   地址或模型错误 / 限流 / 服务不可用 / 网络不通 / 协议不符）。**不会发送你正在看的字幕**。
7. 关闭开关即停止翻译；**清除 Key** 会同时让运行中的会话重新需要凭据。

安全提示：地址 origin 变化时会**自动清除**已存 Key，避免把凭据发往另一台主机。
产生费用的是你在第 4 步配置的服务账号；只有打开 AI 开关时才会发起翻译请求。

## 4. 日常使用行为

- **预取**：字幕事件会在后台准备**原文时间轴**（每个源最多一次额外读取），与 AI 开关无关；
  同一来源的重复事件不会重复下载，只有真正换源才重新抓取。
- **单请求**：翻译同时最多一个请求在飞；批次有 60 秒窗口、条目数与字符预算上限；缓存有 2,000 条 / 2 MiB 上限。
- **并发与节流**：失败不会无限重试。连续两批失败会进入冷却；429 会按 `Retry-After` 暂停
  （超过 60 秒时状态行显示“已暂停”，原文继续播放）。
- **鉴权失败**：401/403/402 会**停止请求**并在状态行提示（不会被反复重试）；替换 Key 后立即恢复。
- **seek / 换轨 / 换视频**：都会丢弃属于旧位置的译文结果；时间轴按源归属，换源不会串字幕。
- **AI 关闭**：立即回到仅原文，但**不会**丢弃已取得的原文时间轴，本地导出照常可用。

## 5. 导出与文件位置

长按字幕键 → 字幕菜单底部两项：**导出字幕** / **导出诊断日志**。导出在后台进行，播放不中断；
重复点击会被拒绝（同一时间只保留一个导出任务）。

字幕 ZIP（`SmartTube-subtitles-YYYYMMDD-HHmmss.zip`）条目：

| 条目 | 内容 |
| --- | --- |
| `original.srt` | 原文，覆盖已取得时间轴的整条视频 |
| `translated.srt` | 仅译文；缺失处回退原文（**有译文时**才生成） |
| `bilingual.srt` | 原文在上、译文在下（**有译文时**才生成） |
| `untranslated.srt` | 只含**仍无译文**的 cue，可直接播放（存在缺失时才生成） |
| `translation-status.txt` | 逐条 `TRANSLATED` / `FAILED` / `NOT_ATTEMPTED` + 时间码 + 原文一行 + 汇总 |
| `README.txt` | 覆盖范围、回退规则、缓存淘汰说明、末条结束时间为估算 |

诊断日志（`SmartTube-diagnostics-YYYYMMDD-HHmmss.txt`）采用 35 项字段白名单：版本、设备、
字幕来源类型/声明 MIME、快照状态、时间轴帧数/条目数、缓存与批次计数、显示模式、有限事件码。
**不含** Key、Authorization、Cookie、账号、签名 URL、HTTP 正文、字幕正文、logcat、偏好设置；**不会自动上传**。

写入行为：Android 10+ 复用 `MediaStoreFile`（无需存储权限）；旧版本直写公共目录并使用存储权限。
写入后回读校验，只有能完整读回才算成功；**不覆盖同名文件**；空间不足/权限拒绝/无可用目录都有明确提示。

## 6. 故障恢复对照

| 现象 | 含义与处理 |
| --- | --- |
| 状态行“AI 翻译需要 API Key” | 还没配置 Key：进入 AI 翻译设置输入，或用“测试连接”确认 |
| 状态行“密钥被拒绝” | 401/403/402：核对 Key、服务地址与账户余额；替换 Key 后立即恢复 |
| 状态行“翻译已暂停，暂时显示原文” | 限流/连续失败冷却：等待提示时间，或检查网络 |
| “测试连接”提示地址或模型错误 | 服务地址须为 `https`（例如 `https://api.deepseek.com`，可带 `/v1`），模型名要与服务一致 |
| 导出提示“没有时间轴” | 原文时间轴尚未就绪（或该源不被支持）：确认已选中一条**文本**字幕轨，稍等几秒再试；**不需要**开 AI 或填 Key |
| 导出提示权限/空间/同名 | 按提示授予存储权限、清理空间；同名文件永不覆盖，会另存新时间戳文件 |

- [ ] 从本仓库 release 页面下载本次候选（见交付记录中的 tag），核对 `SHA256SUMS.txt` 与文件哈希。
- [ ] 安装成功；设置里显示的版本号与交付记录一致。
- [ ] 长按字幕键能看到 AI 区：开关、目标语言、三种显示模式、服务地址、模型、翻译风格、Key 设置、测试连接、状态行、两个导出按钮。
- [ ] 遥控器可达性：所有条目可用方向键聚焦，输入框弹出系统键盘，返回键能退出且不误触导出。
- [ ] 不配 Key、不开 AI：选中一条文本字幕轨后，**导出字幕**成功，ZIP 内含 `original.srt`/`untranslated.srt`/`translation-status.txt`/`README.txt`。
- [ ] **导出诊断日志**成功，文件在 `Documents/SmartTube/Exports/`，用电视文件管理器可见并能复制到 U 盘。
- [ ] 导出期间播放不中断，遥控器操作正常。
- [ ] 配置 Key → **测试连接**返回“连接正常”。
- [ ] 播放有字幕的视频 → 开 AI → 三种模式切换即时生效，译文正确、seek/换轨后不串字幕。
- [ ] 翻译成功/部分成功/关闭 AI 后分别导出，确认 `translated.srt`/`bilingual.srt` 与状态文件一致。

## 8. 交付物与后续发布

本次候选的 commit / workflow run / tag / APK 清单 / SHA-256 / 签名证书见
[`plans/evidence/subtitle-ai-rc-delivery-2026-09-20.md`](plans/evidence/subtitle-ai-rc-delivery-2026-09-20.md)。

**验收通过后如何原样发布 stable**：不需要重新开发或打包。

- 若候选是**项目签名**的 RC：直接 `gh release edit <同一 tag> --prerelease=false`（或把同一批资产作为正式 release 发布）即可，
  APK 字节不变。
- 若候选是**debug 签名回退**：它**不能**作为最终 stable 产物（签名身份不稳定，跨 runner 会变，无法长期覆盖升级）。
  必须先提供 4 个签名 Secrets（`SIGNING_KEY` / `KEY_STORE_PASSWORD` / `ALIAS` / `KEY_PASSWORD`），
  然后用 `workflow_dispatch` + `release_mode=true` 重新产出**项目签名 RC**；该路径缺 Secrets 会直接失败，
  不会退回 debug 包。此时 APK 的 `versionCode` 为预留稳定号（`2444`）、`versionName` 为 `32.53`，
  验收通过后再提升为正式 release 即可。

## 9. 明确未完成 / 未验证的缺项

1. **项目签名身份未建立**：仓库没有任何 Secrets，因此当前只有 debug 签名回退候选，**不是**可长期升级的产物。
   需要的 4 个 Secrets 名称与用法见上一节；注入后即可产出项目签名 RC（CI 已就绪，且有缺签名即失败的硬门禁）。
2. **设备验收未完成**：第 7 节清单里除“无 AI/无 Key 的原文导出”和“诊断导出”已在 TCL/Android 11 上通过外，
   译文形态、权限拒绝、空间不足、焦点细节、导出期间播放连续性均**没有设备证据**。
3. **真实服务联调未完成**：没有使用真实 Key 发起过付费调用；“测试连接”与翻译路径只在本机合成服务
   （`SubtitleOkHttpWireTest`）与 fake transport 上验证过。真实 401/429/余额不足等分类未在真机确认。
4. **真实 Android Keystore / 备份导出未验证**：加密存取、no-backup 目录与“备份不含 Key”只有 JVM/Robolectric
   级证据；API 17–22 的内存 Key 分支没有低版本设备证据。
5. **支持范围**：可取得完整文本字幕的 VOD（手工字幕、ASR、DASH/SABR 合并源）为声明支持范围；
   直播滚动字幕、位图字幕（PGS/VOBSUB）与外部播放器明确降级为仅原文。
6. **已知次要限制**：`translation-status.txt` 只能区分“尝试过但无结果”与“从未到达”，不逐条保留 HTTP 原因；
   缓存 2,000 条 / 2 MiB 上限可能导致长视频早期条目被淘汰后重新翻译。
